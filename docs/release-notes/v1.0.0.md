# Flux v1.0.0

Flux 的第一个公开版本，面向 macOS 13+ 与 Apple silicon。

## 主要能力

- 使用可配置的 `Caps + Command + 字母` 从任意位置直达目标应用。
- 记住应用最近使用的窗口，并恢复最小化到程序坞的窗口。
- 单击 Caps 返回上一个普通办公应用，过滤截图浮层和 accessory 应用。
- 将物理 Caps 用作 Right Control 语义，并提供可配置的全局键盘映射。
- 原生三页签设置页，可编辑应用绑定、快捷键、映射范围、权限和开机启动。
- 配置原子保存、冲突校验与 v1 → v2 迁移。
- 无菜单栏图标、无程序坞常驻、无鼠标/焦点/暂停功能。

## 本版修复

- 应用激活完成后再执行窗口恢复，避免 Finder → Codex 和最小化窗口恢复的时序竞态。
- Finder 使用现有窗口时主动取消最小化并置顶。
- 设置页顶部改为原生紧凑分段导航，避免工具栏选中按钮纵向变形。
- 快捷键录制期间暂停 Flux 输入路由，防止已有映射污染录制结果。
- 修复 Caps 与预先按下的 Command/Option/Shift 释放事件配对。
- 登录启动器使用精确 bundle URL，禁止运行实例替代、用户提示和新实例。

## 安装与校验

下载 `Flux.app.zip` 与 `Flux.app.zip.sha256` 后：

```bash
shasum -a 256 -c Flux.app.zip.sha256
```

本次规范归档 SHA-256：

```text
c46ff6319895698382c3d30e1bc898f87520605f49667d7cca439b0749be472b
```

七文件内容 manifest SHA-256：

```text
5c12012b7ed3178427d73245c64493b95f02932609734ec182625b383a01c2f6
```

解压并将 `Flux.app` 放入 `/Applications`，然后授予 Accessibility 与 Input Monitoring。

## 分发说明

`v1.0.0` 二进制为 ad-hoc 签名且未经过 Apple notarization；Release 提供
`Flux.app.zip`、`Flux.app.zip.sha256`、`Flux.app.sha256` 和 `build-info.txt`。
首次打开可能需要在 Finder 中右键应用并选择“打开”。ad-hoc 身份变更后，系统权限列表里
原有开关可能需要关闭再打开，才能让新构建获得 Accessibility 与 Input Monitoring。

当前候选仅构建 `arm64`，不支持 Intel Mac。
